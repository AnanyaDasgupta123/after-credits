# After the Credits 🎬

A responsive, cinema-inspired movie collection website built with HTML and Tailwind CSS as part of the Mint Technology Internship — Milestone 01.

## About the Project

After the Credits is a dark, cinematic-themed website celebrating memorable films across different genres and moods. It features a curated collection of movies, interactive navigation, and a responsive layout.

## Features

- Responsive design for desktop and mobile screens
- Dark cinematic theme with subtle gold accents
- Curated collection of films
- Mood-based browsing section
- Interactive buttons and navigation
- Smooth scrolling and hover effects

## Tech Stack

- HTML5
- Tailwind CSS
- Node.js and npm for Tailwind CSS tooling

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) before running the project locally.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd after-the-credits
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Build the CSS:

   ```bash
   npm run build
   ```

5. Open `index.html` in your browser, or use the VS Code Live Server extension.
